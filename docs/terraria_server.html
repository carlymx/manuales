Configuración de Servidor Terraria en Orange Pi

Introducción

Esta guía detalla cómo configurar un servidor de Terraria con TShock en una Orange Pi. TShock es una capa de seguridad y administración para servidores de Terraria que permite controlar usuarios, proteger mundos y gestionar comandos.

Orange Pi es una placa de desarrollo similar a Raspberry Pi, basada en ARM, que puede utilizarse eficientemente para alojar servidores ligeros como Terraria.

Instalación del Servidor

1. Crear un Nuevo Usuario y Darle Privilegios

Es recomendable crear un usuario dedicado para el servidor de Terraria para mantener la seguridad del sistema:

sudo adduser terraria

Edita el archivo sudoers para otorgar privilegios al nuevo usuario:

sudo visudo

Al final del archivo, añade:

# Super Usuarios
root    ALL=(ALL:ALL) ALL
terraria    ALL=(ALL:ALL) ALL

2. Instalar Programas Necesarios

Instala Mono (entorno para ejecutar aplicaciones .NET), Screen (para mantener el servidor en ejecución) y herramientas de compresión:

sudo apt-get install mono-complete screen zip unzip

3. Cambiar al Nuevo Usuario

su terraria

4. Navegar al Directorio Home

cd ~

5. Descargar la Última Versión de TShock

Descarga la última versión de TShock desde su repositorio oficial. Visita https://github.com/Pryaxis/TShock/releases/ para obtener el enlace más reciente.

Por ejemplo:

wget https://github.com/Pryaxis/TShock/releases/download/v4.3.26/tshock_4.3.26.zip

6. Descomprimir el Archivo

Extrae el contenido del archivo ZIP a un nuevo directorio:

unzip tshock_4.3.26.zip -d ./server

7. Iniciar por Primera Vez el Servidor

Navega al directorio del servidor y ejecútalo por primera vez:

cd server
mono-sgen TerrariaServer.exe

Sigue las instrucciones en pantalla para crear un nuevo mundo:

  1. Selecciona la opción para crear un nuevo mundo
  2. Indica el tamaño del mundo
  3. Establece el nombre del mundo
  4. Configura las opciones que desees

Después de crear y cargar el mundo por primera vez, cierra el servidor con el comando:

exit

Configuración del Servidor

8. Crear un Script de Inicio

Crea un archivo ejecutable para iniciar el servidor fácilmente:

touch Iniciar_Server.sh && chmod +x Iniciar_Server.sh

9. Editar el Script de Inicio

Abre el archivo para editar las instrucciones de arranque:

nano Iniciar_Server.sh

Añade el siguiente contenido (ajusta la ruta al mundo según tu configuración):

#!/bin/bash
screen -S terraria -A -m \
    mono-sgen TerrariaServer.exe \
    -world "/home/terraria/server/worlds/mundo1.wld" \
    -port 7777 \
    -maxplayers 8

10. Iniciar el Servidor

Ejecuta el script para iniciar el servidor:

./Iniciar_Server.sh

Comandos de Servidor Comunes

Los siguientes comandos pueden usarse una vez que estés conectado al servidor como administrador:

  • /maxplayers [número] - Establece el máximo de jugadores permitidos (ej. /maxplayers 8)
  • /port [puerto] - Cambia el puerto del servidor (ej. /port 7778)
  • /exit - Cierra el servidor de forma segura
  • /save - Guarda el mundo actual
  • /kick [jugador] - Expulsa a un jugador
  • /ban [jugador] - Banea a un jugador
  • /password [contraseña] - Establece una contraseña para el servidor

Comandos de GNU Screen

Para interactuar con el servidor en ejecución:

  • screen -r terraria - Conectarse a la sesión del servidor
  • Ctrl+A, D - Desconectarse de la sesión (el servidor sigue ejecutándose)
  • screen -list - Ver sesiones de screen activas

Ubicaciones de Archivos Importantes

Ubicaciones de Mundos por Sistema Operativo

  • Windows: C:\Users\[nombre_usuario]\Documents\My Games\Terraria\Worlds
  • Steam (por defecto): C:\Program Files (x86)\Steam\userdata\[ID]\105600\remote\worlds
  • Mac: ~/Library/Application Support/Terraria/Worlds
  • Linux (nuestra configuración): ~/server/worlds (relativo al directorio del usuario terraria)

Otros Archivos Importantes

  • Configuración de TShock: ~/server/config.json
  • Registros del servidor: ~/server/tshock.log
  • Usuarios administradores: ~/server/tshock.sqlite (base de datos)

Transferencia de Mundos

Copiar Mundo desde Windows a Linux usando PSCP

Si tienes un mundo creado en Windows y quieres usarlo en tu servidor Linux:

  1. Descarga PSCP.exe desde PuTTY (disponible en versiones de 32 y 64 bits)
  2. Copia pscp.exe a C:\Windows\system32\ para tenerlo disponible en cualquier directorio
  3. Abre PowerShell o símbolo de sistema
  4. Ejecuta el siguiente comando (ajustando la IP de tu Orange Pi y rutas según tu configuración):
pscp "C:\ruta\al\mundo\Tu_Mapa.wld" terraria@192.168.0.xxx:/home/terraria/server/worlds/

Transferencia en la Dirección Contraria

Para descargar un mundo desde tu Orange Pi a Windows:

pscp terraria@192.168.0.xxx:/home/terraria/server/worlds/Tu_Mapa.wld "C:\ruta\de\destino\"

Alternativa: Transferencia con SCP/SFTP

Desde Linux, puedes usar SCP para transferencias:

scp /ruta/al/mundo.wld usuario@direccion_ip:/ruta/destino/
