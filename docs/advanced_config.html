Configuraciones Avanzadas

Consejos de Rendimiento

Montar Carpetas Temporales en RAM

Si tienes 8GB o más de RAM, puedes mejorar el rendimiento y prolongar la vida útil de un SSD montando las carpetas temporales en RAM:

Edita el archivo /etc/fstab:

sudo nano /etc/fstab

Agrega estas líneas:

tmpfs    /tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,defaults    0    0
tmpfs    /var/tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,defaults    0    0

Si usas frecuentemente mucha RAM (por ejemplo con máquinas virtuales), puedes limitar el tamaño:

tmpfs    /tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,size=2G    0    0

TRIM para Discos SSD

TRIM permite que el SSD administre eficientemente los bloques de espacio vacío. Puedes programar TRIM para que se ejecute semanalmente:

Crea un archivo para la tarea semanal:

sudo nano /etc/cron.weekly/fstrim

Agrega el siguiente contenido:

#!/bin/sh
# Comando para ejecutar TRIM en todos los discos soportados
/sbin/fstrim --all || true

Da permisos de ejecución:

sudo chmod +x /etc/cron.weekly/fstrim

Configuración de Archivo de Intercambio (Swap)

El archivo de swap es crucial para el rendimiento del sistema, especialmente si planeas usar hibernación. Aquí te explico cómo cambiar su tamaño:

# Cambiar tamaño del archivo de intercambio
cd /
sudo swapoff -a
sudo dd if=/dev/zero of=/swapfile bs=1M count=18432  # Tamaño: 18GB
sudo mkswap /swapfile
sudo swapon /swapfile
cat /proc/meminfo | grep Swap

Para hacerlo permanente, asegúrate de que el archivo esté en /etc/fstab:

/swapfile none swap sw 0 0

Reparar GRUB

Si tienes problemas para arrancar Linux después de instalar otro sistema operativo o por algún error del cargador de arranque, puedes usar Boot Repair. Esta herramienta proporciona una interfaz gráfica que puede resolver automáticamente muchos problemas de arranque comunes.

Instalación y uso de Boot Repair

sudo add-apt-repository ppa:yannubuntu/boot-repair
sudo apt-get update
sudo apt-get install -y boot-repair
boot-repair

Opciones alternativas para reparar GRUB

Si prefieres métodos manuales o Boot Repair no está disponible:

  1. Arranca con un USB o CD de Linux Live
  2. Abre una terminal y determina la partición raíz de tu instalación:
    3. sudo fdisk -l
  3. Crea un punto de montaje temporal y monta la partición raíz:
    4. sudo mount /dev/sdXY /mnt

    (Reemplaza sdXY con tu partición raíz real)

  4. Monta otros sistemas de archivos necesarios:
    5. sudo mount --bind /dev /mnt/dev
sudo mount --bind /proc /mnt/proc
sudo mount --bind /sys /mnt/sys
  5. Entra al sistema como root:
    6. sudo chroot /mnt
  6. Reinstala GRUB:
    7. update-grub
grub-install /dev/sdX

    (Reemplaza sdX con tu disco principal)

  7. Sal del entorno chroot y desmonta los sistemas:
    8. exit
sudo umount /mnt/dev
sudo umount /mnt/proc
sudo umount /mnt/sys
sudo umount /mnt
  8. Reinicia el sistema

Activar Hibernación

La hibernación salva el estado actual del sistema a disco y apaga completamente el equipo. Requiere configuración especial:

Requisitos

  • Desactivar Secure Boot en la BIOS
  • Tener suficiente espacio en disco (equivalente a la RAM)

Procedimiento

1. Verifica la cantidad de RAM que tienes:

free

2. Desactiva el swap actual:

sudo swapoff -a

3. Crea un archivo de swap con el tamaño de tu RAM (ejemplo: 16GB):

sudo fallocate -l 16g /swapfile

4. Establece permisos y activa el swap:

sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

5. Asegúrate de que esté en /etc/fstab:

echo '/swapfile swap swap defaults 0 0' | sudo tee -a /etc/fstab

6. Instala y configura uswsusp:

sudo apt install uswsusp
sudo dpkg-reconfigure -pmedium uswsusp

7. Actualiza el sistema de arranque:

sudo update-initramfs -u

8. Para distribuciones basadas en Ubuntu/Linux Mint, edita GRUB:

sudo nano /etc/default/grub

Agrega el UUID de tu partición de swap antes de cerrar las comillas en la línea GRUB_CMDLINE_LINUX_DEFAULT:

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash resume=UUID=UUID_DE_TU_SWAP"

9. Actualiza GRUB:

sudo update-grub

10. Edita el servicio de hibernación:

sudo systemctl edit systemd-hibernate.service

Pega este contenido:

[Service]
ExecStart=
ExecStart=/usr/sbin/s2disk 
ExecStartPost=/bin/run-parts -a post /lib/systemd/system-sleep

11. Crea el archivo de permisos de hibernación:

sudo nano /etc/polkit-1/localauthority/50-local.d/com.ubuntu.enable-hibernate.pkla

Agrega este contenido:

[Re-enable hibernate by default in upower]
Identity=unix-user:*
Action=org.freedesktop.upower.hibernate
ResultActive=yes
 
[Re-enable hibernate by default in logind]
Identity=unix-user:*
Action=org.freedesktop.login1.hibernate;org.freedesktop.login1.hibernate-multiple-sessions
ResultActive=yes

12. Reinicia el sistema para aplicar todos los cambios.

Actualizar Kernel

Actualizar a versiones más recientes del kernel puede solucionar problemas de hardware o proporcionar nuevas características:

Ejemplo de cómo instalar el kernel 5.16.11:

wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-headers-5.16.11-051611_5.16.11-051611.202202230823_all.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-headers-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-image-unsigned-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-modules-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb

sudo dpkg -i linux-headers-5.16.11*.deb linux-modules-5.16.11*.deb linux-image-unsigned-5.16.11-*.deb

Usar Repositorio Debian SID (CUIDADO!)

Para acceder a versiones más recientes de software, puedes añadir el repositorio inestable de Debian (SID). ¡Usa con precaución!

sudo apt update
sudo apt install -y software-properties-common debian-archive-keyring dirmngr
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys 648ACFD622F3D138
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys 0E98404D386FA1D9
sudo add-apt-repository "deb http://ftp.de.debian.org/debian sid main"

NOTA: Desactiva este repositorio antes de actualizar el sistema para evitar inestabilidades.

Otros Consejos de Optimización

Optimizar SSD

Además del TRIM mencionado anteriormente, considera:

  • Montar carpetas temporales en RAM
  • Reducir la escritura en el SSD con ajustes de journaling
  • Usar el scheduler de E/S adecuado (deadline o noop para SSD)

Permisos de Dispositivos USB

Para acceder a dispositivos USB como ttyUSB0 sin ser root:

sudo usermod -a -G tty $USER
sudo usermod -a -G dialout $USER

Reinicia el sistema para aplicar los cambios.
