Advanced Configurations

Performance Tips

Mount Temporary Folders in RAM

If you have 8GB or more of RAM, you can improve performance and extend SSD life by mounting temporary folders in RAM:

Edit the /etc/fstab file:

sudo nano /etc/fstab

Add these lines:

tmpfs    /tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,defaults    0    0
tmpfs    /var/tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,defaults    0    0

If you frequently use lots of RAM (e.g., with virtual machines), you can limit the size:

tmpfs    /tmp    tmpfs    noatime,nodiratime,nodev,nosuid,mode=1777,size=2G    0    0

TRIM for SSD Drives

TRIM allows the SSD to efficiently manage empty space blocks. You can schedule TRIM to run weekly:

Create a file for the weekly task:

sudo nano /etc/cron.weekly/fstrim

Add the following content:

#!/bin/sh
# Command to execute TRIM on all supported disks
/sbin/fstrim --all || true

Give execution permissions:

sudo chmod +x /etc/cron.weekly/fstrim

Swap File Configuration

The swap file is crucial for system performance, especially if you plan to use hibernation. Here's how to change its size:

# Change swap file size
cd /
sudo swapoff -a
sudo dd if=/dev/zero of=/swapfile bs=1M count=18432  # Size: 18GB
sudo mkswap /swapfile
sudo swapon /swapfile
cat /proc/meminfo | grep Swap

To make it permanent, ensure the file is in /etc/fstab:

/swapfile none swap sw 0 0

Repair GRUB

If you have boot issues after installing another OS or due to a bootloader error, you can use Boot Repair. This tool provides a graphical interface that can automatically resolve many common boot problems.

Installation and Use of Boot Repair

sudo add-apt-repository ppa:yannubuntu/boot-repair
sudo apt-get update
sudo apt-get install -y boot-repair
boot-repair

Alternative Options for GRUB Repair

If you prefer manual methods or Boot Repair is not available:

  1. Boot with a Linux Live USB or CD
  2. Open a terminal and determine your root partition of your installation:
    3. sudo fdisk -l
  3. Create a temporary mount point and mount the root partition:
    4. sudo mount /dev/sdXY /mnt

    (Replace sdXY with your actual root partition)

  4. Mount other necessary filesystems:
    5. sudo mount --bind /dev /mnt/dev
sudo mount --bind /proc /mnt/proc
sudo mount --bind /sys /mnt/sys
  5. Enter the system as root:
    6. sudo chroot /mnt
  6. Reinstall GRUB:
    7. update-grub
grub-install /dev/sdX

    (Replace sdX with your main disk)

  7. Exit the chroot environment and unmount filesystems:
    8. exit
sudo umount /mnt/dev
sudo umount /mnt/proc
sudo umount /mnt/sys
sudo umount /mnt
  8. Reboot your system

Enable Hibernation

Hibernation saves the current system state to disk and completely powers off the computer. It requires special configuration:

Requirements

  • Disable Secure Boot in BIOS
  • Have enough disk space (equivalent to RAM)

Procedure

1. Check how much RAM you have:

free

2. Disable current swap:

sudo swapoff -a

3. Create a swap file with the size of your RAM (example: 16GB):

sudo fallocate -l 16g /swapfile

4. Set permissions and activate swap:

sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

5. Ensure it's in /etc/fstab:

echo '/swapfile swap swap defaults 0 0' | sudo tee -a /etc/fstab

6. Install and configure uswsusp:

sudo apt install uswsusp
sudo dpkg-reconfigure -pmedium uswsusp

7. Update boot system:

sudo update-initramfs -u

8. For Ubuntu/Linux Mint-based distributions, edit GRUB:

sudo nano /etc/default/grub

Add your swap partition UUID before closing quotes in the GRUB_CMDLINE_LINUX_DEFAULT line:

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash resume=UUID=YOUR_SWAP_PARTITION_UUID"

9. Update GRUB:

sudo update-grub

10. Edit the hibernation service:

sudo systemctl edit systemd-hibernate.service

Paste this content:

[Service]
ExecStart=
ExecStart=/usr/sbin/s2disk 
ExecStartPost=/bin/run-parts -a post /lib/systemd/system-sleep

11. Create hibernation permissions file:

sudo nano /etc/polkit-1/localauthority/50-local.d/com.ubuntu.enable-hibernate.pkla

Add this content:

[Re-enable hibernate by default in upower]
Identity=unix-user:*
Action=org.freedesktop.upower.hibernate
ResultActive=yes
 
[Re-enable hibernate by default in logind]
Identity=unix-user:*
Action=org.freedesktop.login1.hibernate;org.freedesktop.login1.hibernate-multiple-sessions
ResultActive=yes

12. Reboot the system to apply all changes.

Update Kernel

Updating to newer kernel versions can fix hardware issues or provide new features:

Example of how to install kernel 5.16.11:

wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-headers-5.16.11-051611_5.16.11-051611.202202230823_all.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-headers-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-image-unsigned-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb
wget -c https://kernel.ubuntu.com/~kernel-ppa/mainline/v5.16.11/amd64/linux-modules-5.16.11-051611-generic_5.16.11-051611.202202230823_amd64.deb

sudo dpkg -i linux-headers-5.16.11*.deb linux-modules-5.16.11*.deb linux-image-unsigned-5.16.11-*.deb

Use Debian SID Repository (CAUTION!)

To access newer software versions, you can add the unstable Debian (SID) repository. Use with caution!

sudo apt update
sudo apt install -y software-properties-common debian-archive-keyring dirmngr
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys 648ACFD622F3D138
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys 0E98404D386FA1D9
sudo add-apt-repository "deb http://ftp.de.debian.org/debian sid main"

NOTE: Disable this repository before updating the system to avoid instability.

Other Optimization Tips

SSD Optimization

Besides TRIM mentioned earlier, consider:

  • Mounting temporary folders in RAM
  • Reducing SSD writes with journaling adjustments
  • Using the appropriate I/O scheduler (deadline or noop for SSD)

USB Device Permissions

To access USB devices like ttyUSB0 without being root:

sudo usermod -a -G tty $USER
sudo usermod -a -G dialout $USER

Reboot the system to apply changes.
