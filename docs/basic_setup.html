Configuración Básica de Linux

Primeros Pasos en Linux Mint

Esta sección cubre las configuraciones básicas que se recomiendan realizar justo después de instalar Linux Mint para personalizar tu entorno y mejorar la funcionalidad.

Editar GRUB

El cargador de arranque GRUB puede personalizarse para mejorar la experiencia de arranque:

sudo add-apt-repository ppa:danielrichter2007/grub-customizer
sudo apt update
sudo apt install grub-customizer

Personalizar GRUB

Usa GRUB Customizer para una interfaz gráfica amigable para personalizar el menú de arranque:

sudo add-apt-repository ppa:danielrichter2007/grub-customizer
sudo apt update
sudo apt install grub-customizer

Configurar Escritorio Remoto

Para acceder a tu sistema de forma remota, instala y configura XRDP:

sudo apt install xrdp
sudo systemctl enable xrdp
sudo service xrdp start

Para mejorar la compatibilidad con X11 (opcional):

wget https://raw.githubusercontent.com/scarygliders/X11RDP-o-Matic/master/X11rdp-o-matic.sh
sudo chmod +x X11rdp-o-matic.sh
sudo ./X11rdp-o-matic.sh

Poner a Punto Arduino IDE

Para que el usuario pueda usar Arduino IDE sin problemas de permisos:

sudo usermod -a -G dialout $USER

Para dispositivos Digispark, crea las reglas de udev:

sudo nano /etc/udev/rules.d/49-micronucleus.rules

Agregar el siguiente contenido al archivo:

# UDEV Rules for Micronucleus boards including the Digispark.
# This file must be placed at:
#
# /etc/udev/rules.d/49-micronucleus.rules    (preferred location)
#   or
# /lib/udev/rules.d/49-micronucleus.rules    (req'd on some broken systems)
#
# After this file is copied, physically unplug and reconnect the board.
#
SUBSYSTEMS=="usb", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666"
KERNEL=="ttyACM*", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666", ENV{ID_MM_DEVICE_IGNORE}="1"
#
# If you share your linux system with other users, or just don't like the
# idea of write permission for everybody, you can replace MODE:="0666" with
# OWNER:="yourusername" to create the device owned by you, or with
# GROUP:="somegroupname" and mange access using standard unix groups.

Recarga las reglas:

sudo udevadm control --reload-rules

Instalar PyQt5

Para desarrollo de interfaces gráficas en Python:

sudo apt install pyqt5-dev-tools pyqt5-examples python3-pyqt5 python3-qtpy

Soporte para Particiones NTFS

Instala los paquetes necesarios para soporte completo de NTFS:

sudo apt install ntfs-3g ntfs-config

Para montar particiones NTFS en el archivo /etc/fstab:

#UUID=UUID_DE_LA_PARTICION /punto_de_montaje ntfs-3g defaults,locale=es_ES.UTF-8 0 0

# Ejemplo:
UUID=5CCC2306CC22DA52 /media/Almacen ntfs-3g defaults,locale=es_ES.UTF-8 0 0

Problemas Comunes con Particiones NTFS

Si no puedes montar una partición NTFS de Windows, probablemente sea debido a la hibernación rápida de Windows 8/10. Para solucionar esto:

  1. Desactiva la hibernación en Windows: 
    powercfg /h off
  2. O desactiva la "Inicio rápido" en las opciones de energía de Windows

Reparar Particiones NTFS

Si una partición NTFS tiene errores:

sudo ntfsfix /dev/sdXY

Donde sdXY es tu dispositivo (por ejemplo, sda1).
