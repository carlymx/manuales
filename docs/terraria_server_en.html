Setting Up Terraria Server on Orange Pi

Introduction

This guide details how to set up a Terraria server with TShock on an Orange Pi. TShock is a security and administration layer for Terraria servers that allows you to control users, protect worlds, and manage commands.

Orange Pi is a development board similar to Raspberry Pi, based on ARM architecture, which can be used effectively to host lightweight servers like Terraria.

Server Installation

1. Create a New User and Grant Privileges

It's recommended to create a dedicated user for the Terraria server to maintain system security:

sudo adduser terraria

Edit the sudoers file to grant privileges to the new user:

sudo visudo

At the end of the file, add:

# Super Users
root    ALL=(ALL:ALL) ALL
terraria    ALL=(ALL:ALL) ALL

2. Install Required Programs

Install Mono (environment for running .NET applications), Screen (to keep the server running), and compression tools:

sudo apt-get install mono-complete screen zip unzip

3. Switch to the New User

su terraria

4. Navigate to the Home Directory

cd ~

5. Download the Latest TShock Version

Download the latest TShock version from its official repository. Visit https://github.com/Pryaxis/TShock/releases/ to get the most recent link.

For example:

wget https://github.com/Pryaxis/TShock/releases/download/v4.3.26/tshock_4.3.26.zip

6. Extract the Archive

Extract the ZIP file contents to a new directory:

unzip tshock_4.3.26.zip -d ./server

7. Initialize the Server for the First Time

Navigate to the server directory and execute it for the first time:

cd server
mono-sgen TerrariaServer.exe

Follow the on-screen instructions to create a new world:

  1. Select the option to create a new world
  2. Specify the world size
  3. Set the world name
  4. Configure the options you want

After creating and loading the world for the first time, close the server with the command:

exit

Server Configuration

8. Create a Startup Script

Create an executable file to easily start the server:

touch Start_Server.sh && chmod +x Start_Server.sh

9. Edit the Startup Script

Open the file to edit the startup commands:

nano Start_Server.sh

Add the following content (adjust the world path according to your configuration):

#!/bin/bash
screen -S terraria -A -m \
    mono-sgen TerrariaServer.exe \
    -world "/home/terraria/server/worlds/world1.wld" \
    -port 7777 \
    -maxplayers 8

10. Start the Server

Execute the script to start the server:

./Start_Server.sh

Common Server Commands

The following commands can be used once you're connected to the server as an administrator:

  • /maxplayers [number] - Sets the maximum number of allowed players (e.g. /maxplayers 8)
  • /port [port] - Changes the server port (e.g. /port 7778)
  • /exit - Shuts down the server safely
  • /save - Saves the current world
  • /kick [player] - Kicks a player
  • /ban [player] - Bans a player
  • /password [password] - Sets a password for the server

GNU Screen Commands

To interact with the running server:

  • screen -r terraria - Connect to the server session
  • Ctrl+A, D - Disconnect from the session (server continues running)
  • screen -list - View active screen sessions

Important File Locations

World Locations by Operating System

  • Windows: C:\Users\[username]\Documents\My Games\Terraria\Worlds
  • Steam (default): C:\Program Files (x86)\Steam\userdata\[ID]\105600\remote\worlds
  • Mac: ~/Library/Application Support/Terraria/Worlds
  • Linux (our setup): ~/server/worlds (relative to terraria user directory)

Other Important Files

  • TShock Configuration: ~/server/config.json
  • Server Logs: ~/server/tshock.log
  • Admin Users: ~/server/tshock.sqlite (database)

World Transfer

Copy World from Windows to Linux using PSCP

If you have a world created in Windows and want to use it in your Linux server:

  1. Download PSCP.exe from PuTTY (available in 32-bit and 64-bit versions)
  2. Copy pscp.exe to C:\Windows\system32\ to make it available from any directory
  3. Open PowerShell or Command Prompt
  4. Execute the following command (adjusting your Orange Pi IP and paths according to your configuration):
pscp "C:\path\to\world\Your_Map.wld" terraria@192.168.0.xxx:/home/terraria/server/worlds/

Reverse Direction Transfer

To download a world from your Orange Pi to Windows:

pscp terraria@192.168.0.xxx:/home/terraria/server/worlds/Your_Map.wld "C:\destination\path\"

Alternative: SCP/SFTP Transfer

From Linux, you can use SCP for transfers:

scp /path/to/world.wld user@ip_address:/destination/path/
