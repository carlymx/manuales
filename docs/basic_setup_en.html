Basic Linux Setup

First Steps in Linux Mint

This section covers basic configurations recommended to perform immediately after installing Linux Mint to customize your environment and improve functionality.

Customize GRUB

GRUB bootloader can be customized to improve boot experience:

sudo add-apt-repository ppa:danielrichter2007/grub-customizer
sudo apt update
sudo apt install grub-customizer

Customize GRUB

Use GRUB Customizer for a user-friendly graphical interface to customize the boot menu:

sudo add-apt-repository ppa:danielrichter2007/grub-customizer
sudo apt update
sudo apt install grub-customizer

Configure Remote Desktop

To access your system remotely, install and configure XRDP:

sudo apt install xrdp
sudo systemctl enable xrdp
sudo service xrdp start

To improve X11 compatibility (optional):

wget https://raw.githubusercontent.com/scarygliders/X11RDP-o-Matic/master/X11rdp-o-matic.sh
sudo chmod +x X11rdp-o-matic.sh
sudo ./X11rdp-o-matic.sh

Set Up Arduino IDE

To allow the user to use Arduino IDE without permission issues:

sudo usermod -a -G dialout $USER

For Digispark devices, create the udev rules:

sudo nano /etc/udev/rules.d/49-micronucleus.rules

Add the following content to the file:

# UDEV Rules for Micronucleus boards including the Digispark.
# This file must be placed at:
#
# /etc/udev/rules.d/49-micronucleus.rules    (preferred location)
#   or
# /lib/udev/rules.d/49-micronucleus.rules    (req'd on some broken systems)
#
# After this file is copied, physically unplug and reconnect the board.
#
SUBSYSTEMS=="usb", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666"
KERNEL=="ttyACM*", ATTRS{idVendor}=="16d0", ATTRS{idProduct}=="0753", MODE:="0666", ENV{ID_MM_DEVICE_IGNORE}="1"
#
# If you share your linux system with other users, or just don't like the
# idea of write permission for everybody, you can replace MODE:="0666" with
# OWNER:="username" to create the device owned by you, or with
# GROUP:="groupname" and mange access using standard unix groups.

Reload the rules:

sudo udevadm control --reload-rules

Install PyQt5

For GUI development in Python:

sudo apt install pyqt5-dev-tools pyqt5-examples python3-pyqt5 python3-qtpy

NTFS Partition Support

Install necessary packages for full NTFS support:

sudo apt install ntfs-3g ntfs-config

To mount NTFS partitions in the /etc/fstab file:

#UUID=UUID_OF_THE_PARTITION /mount_point ntfs-3g defaults,locale=en_US.UTF-8 0 0

# Example:
UUID=5CCC2306CC22DA52 /media/Storage ntfs-3g defaults,locale=en_US.UTF-8 0 0

Common NTFS Partition Issues

If you can't mount a Windows NTFS partition, it's likely due to Fast Startup in Windows 8/10. To fix this:

  1. Disable hibernation in Windows: 
    powercfg /h off
  2. Or disable "Fast Startup" in Windows power options

Repair NTFS Partitions

If an NTFS partition has errors:

sudo ntfsfix /dev/sdXY

Where sdXY is your device (for example, sda1).
